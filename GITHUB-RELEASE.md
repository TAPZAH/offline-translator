# Текст для релиза GitHub (beta 0.995)

## Tag

`v0.995-beta`

## Заголовок

Оффлайн Переводчик beta 0.995

## Описание

Бета 0.995: настройки с боковым меню, тёмная тема без системных пятен, новые иконки.

Что изменилось:
- настройки перестроены: слева Языки / Поведение / Темы / О программе;
- языковые пакеты ставятся из «Настройки» → «Языки»;
- тёмная тема красит поля ввода, списки и заголовок окна Windows;
- шрифты чётче за счёт DPI-aware отрисовки и Segoe UI;
- кнопка «Настройки» не пропадает при открытии из трея;
- в «Поведении» рамка «Сейчас работает» сразу показывает активные режимы;
- новые иконки темы (жёлтая и синяя стрелки);
- исправлен Argos в портативной сборке: SentencePiece открывает модели в папках с кириллицей, при недоступном argos-net.com используется зеркало data.argosopentech.com.

Вложения релиза **без языковых моделей** — модели ставятся из «Настройки» → «Языки».
Архив `portable-with-models` собирается локально, на GitHub не выкладывается.

Нужны Windows 10/11 x64.
Автор: TAP3AH.
