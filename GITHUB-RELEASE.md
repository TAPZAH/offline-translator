# Текст для релиза GitHub (beta 0.97)

## Tag

`v0.97-beta`

## Заголовок

Оффлайн Переводчик beta 0.97

## Описание

Первый публичный бета-релиз оффлайн-переводчика для Windows.

Что внутри:
- три движка: Firefox Translations, Argos Translate, NLLB-200;
- перевод в окне, из трея и по выделенному тексту;
- автозагрузка в настройках;
- лог ошибок в `data\error.log`.

Вложения релиза **без языковых моделей** — модели ставятся из окна «Языки...».
Архив `portable-with-models` на GitHub не выкладывается.

Нужны Windows 10/11 x64.
