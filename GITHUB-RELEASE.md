# Текст для релиза GitHub (beta 0.98)

## Tag

`v0.98-beta`

## Заголовок

Оффлайн Переводчик beta 0.98

## Описание

Бета 0.98: исправления памяти при смене движка и управление языковыми моделями.

Что изменилось:
- при смене движка старые потоки и модели выгружаются, а не копятся в памяти;
- кнопка выделения текста корректно останавливается при выходе;
- в окне «Языки...» можно удалить пакет или скачать его заново;
- повреждённая модель NLLB больше не считается установленной.

Вложения релиза **без языковых моделей** — модели ставятся из окна «Языки...».
Архив `portable-with-models` на GitHub не выкладывается.

Нужны Windows 10/11 x64.
