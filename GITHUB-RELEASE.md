## Описание

Бета 0.99: быстрый CPU-перевод, движок MarianMT, темы и журнал работы.

Что изменилось:
- C++-сборка CTranslate2 переведена на OpenBLAS + oneDNN + OpenMP — перевод Argos/NLLB больше не занимает десятки секунд;
- новый движок **MarianMT** (Helsinki-NLP OPUS-MT) в Python и C++, пакеты ставятся из окна «Пакеты»;
- светлая и тёмная темы, иконки трея и кнопки выделения;
- постоянный журнал `data/app.log` (переводы, сон/пробуждение, загрузки);
- загрузка моделей Firefox с CDN Mozilla / Remote Settings;
- в настройках указаны версия и автор.

Вложения релиза **без языковых моделей** — модели ставятся из окна «Пакеты» / «Языки...».
Архив `portable-with-models` на GitHub не выкладывается.

Нужны Windows 10/11 x64.
Автор: TAP3AH.
